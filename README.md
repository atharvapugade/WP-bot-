# Tomato FM Kolhapur (94.3 FM) – WhatsApp Chatbot Demo

A realistic WhatsApp Web-inspired customer support chatbot demo designed and built for **Tomato FM Kolhapur (94.3 FM)**, Maharashtra, India.
*Aapla Kolhapur, Aapla Tomato FM!*

---

## 🌟 Key Features

- **Tomato FM Kolhapur (94.3 FM) Branding**:
  - Official Tomato FM logo badge with tomato stem & 94.3 FM styling.
  - Tagline: *"Aapla Kolhapur, Aapla Tomato FM!"*
  - Generated HD station banner graphic featuring the DJ tomato mascot, microphone, and Kolhapur city skyline.

- **🌗 Light & Dark Theme Toggle**:
  - Seamless one-click switch between **WhatsApp Dark Theme** (exact match to screenshot) and **WhatsApp Light Theme**.
  - Persistent theme selection stored in `localStorage`.

- **📱 WhatsApp Desktop & Mobile Split View**:
  - Two-column layout with the **left sidebar visible by default** on desktop.
  - Rich dummy chats (RJ Shrikant, Tomato FM Ad Desk, Listeners Club 📻, RJ Meera, Food Festival Promos).
  - Filter pills (`All`, `Unread`, `Favourites`, `Groups`) and archived row.
  - Full-screen mobile view with responsive drawer toggle.

- **💬 8 Automated Customer Support Workflows**:
  1. 📢 Radio Advertisement
  2. 🎂 Birthday Wishes
  3. 💐 Anniversary Wishes
  4. ❤️ Special Greetings & Dedications
  5. 🎙️ New Shows & Programme Information
  6. 🎉 Event & Promotional Campaigns
  7. 📻 General Enquiry (AI powered with Google Gemini & Marathi/Hindi support)
  8. 👨‍💼 Talk to Our Team

- **⚡ Global Commands**: `MENU`, `RESTART`, `BACK`, `CANCEL`, `HUMAN`, `STATUS`.

---

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open in browser
http://localhost:3000
```
